# Тоғызқұмалақ (Togyzqumalak) — Правила Игры (Rule Set)

Настоящий документ фиксирует строгие правила классического Тоғызқұмалақ, используемые в Game Engine (v2) на платформе ULY DALA. Правила основаны на международных стандартах (Всемирная Федерация Тоғызқұмалак). Любые изменения логики должны строго соответствовать этому документу.

## 1. Доска и Начальное Состояние
- **Игроки**: 2 игрока.
- **Структура**: Доска состоит из 18 отау (лунок) — по 9 для каждого игрока, и 2 қазанов (накопителей).
- **Нумерация**: Отау нумеруются от 1 до 9 для каждого игрока слева направо со стороны игрока.
  - В памяти движка (Linear Array): индексы `0..8` — сторона Игрока 1, `9..17` — сторона Игрока 2.
- **Құмалақ (камни)**: В начале игры в каждом отау лежит ровно 9 камней. (Всего 162 камня, по 81 у каждого).
- **Қазан**: Изначально пуст.

## 2. Механика Хода (Distribution / Sowing)
Ход состоит из взятия всех камней из одного из своих отау и распределения их по доске против часовой стрелки.

- Игрок выбирает любое свое отау, в котором есть хотя бы 1 камень.
- **Если выбран отау с 1 камнем**: Этот камень перекладывается в следующее отау, а исходное становится пустым (0).
- **Если выбран отау с N > 1 камнями**: Игрок оставляет **один камень** в исходном отау, а остальные (N-1) камней раскладывает по одному в каждое последующее отау против часовой стрелки, пока они не закончатся.

## 3. Захват (Capture)
- Если **последний камень** падает в отау **противника**, и общее количество камней в этом отау становится **ЧЕТНЫМ** (2, 4, 6, 8, 10 и т.д.), происходит Захват.
- Все камни из этого отау изымаются и переносятся в қазан игрока, сделавшего ход.

## 4. Тұздық (Священная лунка / Туздык)
Тұздық — это отау противника, выигранное игроком на всю оставшуюся партию.
- Если **последний камень** падает в отау **противника**, и общее количество камней в этом отау становится равным **РОВНО 3**, игрок может объявить это отау своим Тұздық.
- **Ограничения для Тұздық**:
  1. Тұздық **не может** быть создан в 9-м отау противника (индекс 8 для его стороны).
  2. Игрок может иметь только **ОДИН** Тұздық за игру.
  3. Правило симметрии: Игрок **не может** создать Тұздық в отау под номером X, если противник УЖЕ имеет Тұздық в отау под номером X. (Например, если Игрок 1 захватил Тұздық в 3-м отау Игрока 2, то Игрок 2 больше не может создать Тұздық в 3-м отау Игрока 1).
- **Эффект Тұздық**: При создании Тұздық, все 3 камня из него уходят в қазан игрока. В дальнейшем любой камень, падающий в этот Тұздық (неважно чей ход), немедленно забирается в қазан владельца Тұздық.

## 5. Атсырау (Остаться без коня)
- Если после хода игрока на его стороне не осталось ни одного камня (все отау равны 0), и наступает его следующий ход, он не может сделать ход. Это ситуация **Атсырау**.
- В этом случае противник забирает все оставшиеся на его стороне камни в свой қазан.
- Партия завершается.

## 6. Завершение Игры (Win Condition)
- Партия завершается досрочно, если один из игроков набирает в своем қазане **82 камня или более** (он объявляется победителем).
- Партия завершается по правилу Атсырау, после чего подсчитываются камни.
- Если у обоих игроков в конце оказывается ровно по **81 камню**, объявляется **Ничья (Draw)**.
